# Уточнения организаторов

Источник: рабочий Telegram-экспорт. Персональные данные, имена и нерелевантная
переписка намеренно не перенесены.

- Боевые запросы сотрудников не передаются; демонстрационный набор должна
  сгенерировать команда.
- Переданный файл показывает структуру записи в колонке БД, а не полный
  производственный датасет.
- Маленький пример нужен для понимания структуры; реальные payload агента
  могут достигать примерно 100k токенов.
- Интерфейс будущих моделей описан как OpenAI-compatible.
- Дашборд опционален: основная ценность — воспроизводимая методология и сервис.
- На защите можно показывать собственный набор; важна воспроизводимость
  результата на другой выборке.
- Дополнительный сервис извлечения данных может быть преимуществом, но не
  определяет решение.
