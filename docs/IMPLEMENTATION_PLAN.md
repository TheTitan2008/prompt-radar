# План первой рабочей части

1. Безопасно распаковать и потоково провалидировать контракт `dataset.zip`.
2. Восстановить задачи на уровне `run_id`, отдельно сегментируя записи без ID.
3. Message-aware извлечь текущую цель и выбрать один из трёх режимов текста.
4. Извлечь недоверенный текст вложений и выполнить RAG Top-K.
5. Получить нормализованные embeddings через скрытый сервисный интерфейс.
6. Сначала выполнить known matching, затем кластеризовать residual pool.
7. Сохранить интерпретируемые результаты, provisional labels и API payloads.
8. Отдельно оценить predictions по внешнему `ground_truth.jsonl`.
