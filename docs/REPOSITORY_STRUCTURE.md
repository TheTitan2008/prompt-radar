# Структура репозитория

- `src/prompt_radar/` — библиотека и CLI.
- `configs/` — параметры пайплайна, широкие категории и известные use cases.
- `docs/` — контракт данных и краткие выводы по источникам.
- `tests/` — unit-тесты без сети и отдельный integration smoke test.
- `data/sample/` — детерминированный синтетический ZIP и отдельная разметка.
- `data/inbox/`, `data/work/`, `data/processed/` — локальные некоммитируемые
  данные.
- `outputs/` — отдельные атомарно сформированные результаты запусков.
- `.cache/` — embeddings и явно скачанная модель; не коммитируется.
